## Run

Install the .NET 10 SDK, then run:

```sh
dotnet run --project MVC
```

Open http://localhost:5080. Use `dotnet build MVC.slnx` to build and `dotnet test MVC.slnx` to run the tests.

## Group workflow

Start your own feature branch from `dev` and open a PR back to `dev`. We'll merge our pages during the in-person class activity.

The assignment branches are `main`, `release`, `staging`, `test`, `dev`, and `features`. These represent our planned workflow; nothing is deployed.
